{{% objectives %}}

## Objectives

- I can navigate the Soundtrap Sound library and filter loops by instrument, genre, and type.
- I can identify loops by their musical role — drums, bass, harmony, melody, FX.
- I can build separate projects that each hold four loops that sound good together.
- I can describe a loop with music vocabulary instead of "it sounds cool."

{{% /objectives %}}

{{% warmup %}}

## Warmup: What Is a Loop?

Listen to the two-bar drum pattern Mr. Willingham plays on repeat. Be ready to answer out loud: what is a **loop**, and why would a producer build an entire song out of something that repeats?

{{% checkpoint %}}

### Checkpoint: Warmup

- [ ] I can explain what a loop is.
- [ ] I can give one reason a producer builds songs from repeating parts.

{{% /checkpoint %}}

{{% /warmup %}}

{{% worksession %}}

## Work Session: The Sound Library

Watch the demo, then do it yourself. The four moves — set tempo and key first, filter, preview, add — are on [Soundtrap Basics](/music-technology/reference/soundtrap-basics/#the-sound-library), along with the vocabulary (loop, tempo, preview, scale type).

{{% checkpoint %}}

### Checkpoint: Sound Library

- [ ] I set my project's key and tempo before adding loops.
- [ ] I filtered by instrument, genre, and type, and previewed a loop before adding it.

{{% /checkpoint %}}

{{% /worksession %}}

{{% worksession %}}

## Work Session: The Scavenger Hunt

Today is Project Day 1 of [Loops and Layering](/music-technology/projects/loops-and-layering/#project-day-1-scavenger-hunt). Pick up the printed worksheet and read it all the way through.

Five **separate** projects, four loops in each. The five sets and the naming themes are on the project page. For every set, pick four loops that genuinely sound good together, stack them on the timeline, and write every loop name and project name on the worksheet.

{{< callout type="warning" >}}
Check your headphone volume before you start listening. The AudioBox gets much louder than you expect.
{{< /callout >}}

{{% checkpoint %}}

### Checkpoint: Work Session

- [ ] A new, separate project for each set I started.
- [ ] Each finished project has four loops that sound good together.
- [ ] Every project has a school-appropriate name, written on my worksheet with its loop names.

{{% /checkpoint %}}

{{% /worksession %}}

{{% closing %}}

## Closing: Pair-Share

Play a neighbor **one** set and say why those four loops belong together, using the category names from your worksheet — not "it sounds cool."

Save every project, mark which sets are finished, and log off. Tomorrow is another short period and the hunt is due at the end of it.

{{% /closing %}}
