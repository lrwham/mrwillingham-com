{{% worksession %}}

## Work Session: 20 Minutes of Work Time

Finish the Loop Scavenger Hunt. The requirements have not changed — **five separate projects, four loops in each**, every loop chosen because it sounds good with the other three.

| Set | What to collect |
| --- | --- |
| 1   | One loop each from Drums, Bass, Synth, and Piano. |
| 2   | Open the **Genres** menu, pick one genre, and take all four loops from it. |
| 3   | One loop each from Percussion, Strings, Vocal, and Guitar. |
| 4   | Four loops whose names start with the letters **C**, **J**, **L**, and **S**. |
| 5   | Your choice — any four loops you want. |

{{< callout type="warning" >}}
Twenty minutes is not enough time to browse. If you are behind, work in order and stop previewing after three or four options — take the best one you have heard and move on.
{{< /callout >}}

Every project needs a school-appropriate name, and every name needs to be written on your worksheet. A project Mr. Willingham cannot find is a project that does not get graded.

### Checkpoint: Work Session

- [ ] Every project has a school-appropriate name.
- [ ] Every loop name and project name is written on my worksheet.
- [ ] I saved every project.

{{% /checkpoint %}}

{{% /worksession %}}

{{% worksession %}}

## Work Session: Pick One to Share

Tomorrow every person plays **one** set for the class. Choose yours now, while the projects are still open in front of you.

Listen back to all five and pick the one where the four loops fit together best — not the one that took the longest, and not the one with your favorite single loop in it. A set with one amazing loop and three that fight it is a worse pick than four loops that agree with each other.

Circle your pick on your worksheet and be ready to say one sentence about it: **what the four loops are, and why they belong together.**

{{% checkpoint %}}

### Checkpoint: Work Session

- [ ] I listened back to all five sets.
- [ ] I circled my pick on my worksheet.
- [ ] I can name the four loops in it and say why they work together.

{{% /checkpoint %}}

{{% /worksession %}}

Tomorrow you play your pick for the class, so leave that project easy to find.
