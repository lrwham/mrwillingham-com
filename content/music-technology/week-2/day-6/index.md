## Objectives

- I can name the job each category of loop does in a set.
- I can explain why four loops from the same category do not make a song.
- I can build a set by choosing a genre first and filling each job from it.

{{% /objectives %}}

{{% warmup %}}

## Warmup: Five Guitars

Did not finish Friday's rebuild? Do that first. Then: new project, **five guitar loops**, all at the same time. Listen. Good? Bad? Why?

{{% checkpoint %}}

### Checkpoint: Warmup

- [ ] Friday's rebuilt set is finished and saved.
- [ ] I made the five-guitar project and can describe how it sounds.

{{% /checkpoint %}}

{{% /warmup %}}

{{% worksession %}}

## Work Session: Roles, Then Genre

Read [The Four Loop Roles](/music-technology/reference/arranging-loops/#the-four-loop-roles) and [Genre First](/music-technology/reference/arranging-loops/#genre-first). Five guitar loops is one job done five times and three jobs left undone — and filling every job with loops from four different genres still sounds like four songs at once.

Then build one, following [Project Day 4](/music-technology/projects/loops-and-layering/#project-day-4-genre-first): pick a genre you did **not** use in Set 2 of the hunt, set key and tempo, fill each of the four roles once from inside that genre, balance. Name the project after the genre.

{{% checkpoint %}}

### Checkpoint: Work Session

- [ ] I can name the four roles and explain why four loops from one category does not work.
- [ ] I picked a genre before previewing any loops, and set key and tempo.
- [ ] One loop for each role, all from that genre, balanced and saved.

{{% /checkpoint %}}

{{% /worksession %}}

{{% closing %}}

## Closing: Cohesion Check

Play the new set for a neighbor. What genre, and which loop makes it obvious? Is this set more cohesive than Friday's? What made the difference — the genre, the four roles, or the balance?

Tomorrow: drums.
