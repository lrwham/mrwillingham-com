## Work Session: Code.org — Programming with Angry Birds

1. In Clever, click the **Code.org** icon.
2. Open **Programming with Angry Birds** and complete the whole lesson: 11 levels plus the bonus levels.

{{< clever >}}

A **sequence** is a set of instructions that run in order. A **bug** is a mistake that makes a program do the wrong thing. Several of these levels hand you broken code — your job is to find the bug and fix it, not start over.
