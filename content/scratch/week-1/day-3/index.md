## Work Session: Scratch Art Tools

Code matters, but so does how a project looks. We walk through the paint editor together; the full tool-by-tool guide is [Scratch Art Tools](/scratch/reference/art-tools/).

Use the color sliders, the primitive shapes (line, circle, rectangle), and the brush, fill, and text tools to **paint a backdrop** for today's project.

Pick one of the art challenges:

- A castle using only the rectangle and circle tools
- A landscape using only the line tool
- A vehicle using only the brush
