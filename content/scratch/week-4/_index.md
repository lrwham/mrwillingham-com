## Unit: Intermediate Scratch

A four-day week — Tuesday is a student holiday. You start a brand-new project, a falling-objects catch game, while reviewing the skills from Weeks 1–3. The new skill is **cloning**, which lets one sprite create many copies of itself while the game runs. By Friday you have a complete game with a start screen, game-over screen, scoring, lives, and a working clone system. Monday of next week is the unit quiz and the game share-out.
