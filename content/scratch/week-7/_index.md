## Unit: Python and the Terminal

Back from break, you switch from blocks to text. Python is used everywhere in artificial intelligence, data science, and web development; the terminal lets you control a computer with typed commands. Monday and Tuesday are Python basics in VS Code. The middle of the week uses Python to explore a real Pokémon dataset. Friday is a conceptual introduction to artificial intelligence that sets up next week's hands-on machine learning.
