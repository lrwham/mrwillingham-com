Your instructions are posted on this site every class day. Follow the same routine each time.

## Read Everything First

Before you start **any** work, read the whole page: the objectives, the warmup, the work session, and the closing. Knowing where the lesson is going makes the steps make sense.

## The Order of a Lesson

1. **Objectives** — what you should be able to do by the end of class.
2. **Warmup** — a short task you can usually start on your own as soon as you sit down.
3. **Work Session** — the main activity. Some days you can start it on your own. Other days you wait for Mr. Willingham.
4. **Closing** — an exit ticket, a share-out, or a wrap-up.

Each warmup and work session ends with a **checkpoint**. Use it to confirm you did everything before moving on.

## Finished Early?

- Reread the checkpoint and make sure every box is honestly checked.
- Do the extension or "finished early" task on the lesson page, if there is one.
- Otherwise, open Code.org through Clever and keep working at your own pace.

## Lost Work

Scratch sometimes logs you out and drops unsaved work. Save often with `cmd + S` (or **File → Save now**). If a project is lost, most lessons link a **starter project** you can remix to catch up.

## Late Work

Missing work is a zero until it is turned in. Late work is accepted with a one-time 20 point deduction. See the [Course Description](/scratch/description/) for the full policy.
