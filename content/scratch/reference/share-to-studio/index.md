Projects are private until you share them. A shared project has a public link, can be added to a studio, and can be graded. An unshared project cannot.

## Step 1: Share the Project

1. Open your project in the Scratch editor.
2. Give it a real title in the box at the top (not "Untitled-3").
3. Click the orange **Share** button in the top-right corner.
4. On the project page that opens, add short **Instructions** (which keys do what) and, if you like, **Notes and Credits**.

Your project now has a public link. Copy it from the address bar when a lesson or rubric asks for it.

## Step 2: Add It to the Studio

1. Open the class studio link above.
2. Click the **Projects** tab, then **Add Projects**.
3. Pick your project from the list at the bottom, or paste its link.

If you do not see **Add Projects**, make sure you are signed in to your class account and that the studio allows anyone to add projects. Raise your hand if it still does not work.

## Playing Other Projects

Open the studio and click any project to play it. Look at the code too: click **See inside**. Finding the `forever` loop and the `if` blocks inside it is the fastest way to understand how someone else's game works.

## Unsharing

If you shared something by mistake, open the project page and click **Unshare**. Do this only if Mr. Willingham has not graded it yet.
