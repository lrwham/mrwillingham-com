## Design

Criteria
: The things a solution must do to be considered successful. Criteria come from the design brief.

Constraints
: The limits a solution has to fit inside — time, materials, size, cost, safety.

Design Brief
: A short statement from the client that describes the problem and what a solution must accomplish.

Instant Design Challenge
: A design problem with one design, one prototype, and no time to rebuild. You plan first, because you only get one try.

Prototype
: A first working model of a solution, built to test an idea.

Decision Matrix
: A table that scores several solutions against the same criteria so a choice can be made on evidence. Highest row total wins.

Team Norms
: The rules a team agrees to about how it will work together.

## Sketching

Thumbnail Sketch
: A quick, small, freehand sketch that captures the shape and proportion of an object. Fast, not fancy.

Perspective Sketch
: A sketch that shows an object the way the eye sees it, with lines that converge toward a vanishing point.

Isometric Sketch
: A three-dimensional sketch that shows three sides of an object at once. Width and depth lines run at 30 degrees from horizontal, height lines are vertical, and all three dimensions are in true proportion.

Multiview Sketch
: Three flat, straight-on views of an object — TOP, FRONT, and RIGHT — lined up with each other so a builder can measure from them.

Construction Line
: A light guide line drawn first and erased or ignored later. Draw the box, then cut the object out of it.

Object Line
: A heavy, dark line that shows a real edge of the object.

Hidden Line
: A dashed line that shows an edge you cannot see from that view because it is behind part of the object.

Alignment
: The rule that TOP sits directly above FRONT (they share width) and RIGHT sits directly beside FRONT (they share height).

## Measurement and Dimensioning

U.S. Customary System
: Inches, feet, yards, miles. Fractions of an inch are written as fractions: 1-3/16 in., not 1.19 in.

Metric System
: Millimeters, centimeters, meters. Parts of a centimeter are written as decimals: 7.6 cm.

Hatch Marks
: The small lines on a ruler. An inch is split into 16 hatch marks; a centimeter is split into 10.

Dial Caliper
: A precision measuring tool that reads to 0.001 in. The big number comes from the scale on the beam, the small number from the dial. It can measure outside width, inside width, and depth.

Dimension
: A number on a sketch that tells a builder how big something is. Dimension lines have arrowheads; extension lines connect the dimension to the object with a small gap.

Dimensioning Conventions
: The rules for placing dimensions: every size a builder needs exactly once, outside the object, between adjacent views, never on a hidden line, never crossing another line, and with the unit of measure stated on the sheet.

## Statistics

Data
: The numbers you collect from a test — for the skimmer, every launch distance in feet.

Mean
: The average. Add every value and divide by how many there are.

Median
: The middle value when the data are in order. With an even count, the mean of the two middle values.

Mode
: The value that shows up most often. There can be a tie, or no mode at all.

Range
: Maximum minus minimum. Built from exactly two values.

Quartiles
: Q1 is the median of the lower half of the data, Q2 is the median, and Q3 is the median of the upper half. Order the list first — nothing works until you do.

Interquartile Range (IQR)
: Q3 minus Q1. The width of the middle 50% of the data — the box on a box plot.

Five-Number Summary
: Minimum, Q1, median, Q3, maximum. The five numbers a box plot is built from.

Box and Whiskers Plot
: A picture of the five-number summary: a box from Q1 to Q3 with a line at the median, and whiskers out to the minimum and maximum.

Center and Spread
: Center describes a typical value (mean, median). Spread describes how far apart the values are (range, IQR).
