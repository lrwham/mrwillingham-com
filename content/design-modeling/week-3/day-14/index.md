### Key Vocabulary

Mean
: The average — add every value and divide by how many there are.

Median
: The middle value when the data are in order.

Mode
: The value that shows up most often.

Range
: Maximum minus minimum.

Center
: What a typical value looks like — the mean and the median.

Spread
: How far apart the values are — the minimum, the maximum, and the range.
