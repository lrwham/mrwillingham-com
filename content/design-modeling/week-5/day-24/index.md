## Work Session: The Name Tag Challenge

Clever → **myPLTW** → **Activity 2.1**, sections **Get It in Writing** and **This One Has Your Name On It**.

1. Learn the text tool in **Get It in Writing** — add letters to a base, size them, color them.
2. Then build your own name tag. The **design requirements** are listed in the activity — read them before you start, the way you read a design brief. Base height, letter height, and the hole all have exact numbers you must hit. **Type exact dimensions; do not eyeball them.**
3. Evaluate your design against **every** requirement, then answer the notebook prompt: did your tag meet them all, and what would you improve?

{{< callout type="info" >}}
This is a design brief in miniature. Requirements first, build second, evaluate against the requirements last. A gorgeous tag that misses a required dimension is a failed design; a plain tag that hits every number is a successful one. Same rule as the AFO challenge, same rule forever.
{{< /callout >}}

## Work Session: Quiz Review, Out Loud

Laptops closed. Study guide and notebook out. We hit the five skills, fast:

- **Ruler:** find zero first; if the edge is not on zero, subtract. Fractions reduced.
- **Missing view:** alignment rules; solid vs. dashed; one grid square per cube face.
- **Dimensioning:** everything needed, nothing extra, six errors, unit of measure stated — and a view that shows nothing new gets zero.
- **Design process:** six steps, in order, and what each looks like in a real project.
- **Statistics:** order the list first; five values means Q1 and Q3 are averages; a box plot is five numbers; middle 50% = Q3 − Q1.
